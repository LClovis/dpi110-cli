# DPI110-IS Command-line Interface (Unix CLI & Daemon) — Python Script
<!-- A command-line tool that automatically connects to and downloads the DPI-110IS device stored logs. -->

## What does this do?

- Connects to a DPI-110IS device plugged over USB and downloads the device's stored logs
- Runs automatically after installed

## Requirements

Before starting, you need:

| What |  |
|---|---|
| **Linux** | (Debian recommended / [Windows][1]) |
| **Python 3.8 or newer** | Run `python3 --version` in a terminal |
| **The [DPI-110IS] device** | Connected via [USB] |
| **A terminal** | - |

Don't have Python? On Ubuntu/Debian:

```bash
sudo apt update && sudo apt install python3
```

## System Architecture & Operations

### 1. Installation (`--install`)
 
```bash
mkdir -p ~/dpi110-cli && curl -sL https://github.com/LClovis/dpi110-cli/archive/main.tar.gz | tar -xz -C ~/dpi110-cli --strip-components=1 && cd ~/dpi110-cli && sudo python3 dpi110-cli.py --install
```

### 2. Background Daemon (`--daemon`)
Once installed, the systemd service runs continuously in the background to handle autonomous data extraction:
* **Hardware Polling:** Continuously scans `/dev/ttyUSB*` and `/dev/ttyACM*` ports. Upon detecting a connected DPI110-IS device, it issues a `ReadDeviceInfo` command to identify the model and serial number.

* **Data Synchronization:** Sequentially iterates through the device's memory indexes, downloading all Finished Leak Tests and Standard Datalogs.

* **Configuration Sync:** After data extraction, it reads local settings from `config.json` and pushes them to the hardware. This overwrites old device configurations and erases the device's internal memory to prepare it for the next field run.
* **Notifications:** Upon a successful sync, the daemon signals completion by flashing the device's red LED.

### 3. Local Database Schema
Data is stored permanently in `dpi110_logs.db`.
* **`devices`:** Stores hardware profiles, including the serial number, model, firmware version, and physical pressure range limits.
* **`log_samples`:** Stores the high-frequency measurements (maximum, minimum, and mean values for pressure and temperature) generated by standard datalogs. These are linked to the parent `logs` table via a cascading foreign key.

[1]: Only using the '--daemon' flag
